RECORDED CASES + OPTIONAL LIVE AI

A research prototype for novice programmers learning to verify AI-generated debugging suggestions. Select a scenario, inspect the evidence, and make your own decision. Recorded cases are demonstrations. In Live AI mode, model responses are generated dynamically but remain unverified; user code is never executed.

Recorded example: code is read-only.

02 · Diagnosis

Recorded example; not generated in real time.

03 · Verification evidence

Evidence types are labelled. “Recorded test” means an example prepared in advance; no user code is executed by this prototype.

04 · Your decision

Decide only after examining the proposed cause and evidence. This prototype does not change files or execute code.

In recorded mode, re-analysis only records the request. In Live AI mode, it requests a new response using your feedback.
